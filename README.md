# Centene Corporation &middot; Shared Collaboration Hub

Customer-branded GitHub Pages microsite for Centene Corporation.

Tells the "Enterprise Application Value Inversion" executive narrative as an
interactive web experience, following the same click-driven tab/panel format
as the Kaiser Permanente + Risant Health build, reskinned with Centene's own
brand colors and populated with Centene-specific figures.

## Files

| File | Purpose |
|---|---|
| `index.html` | Landing page, published at the root of the repo. Branded with Microsoft + Centene logos. |
| `Centene-App-Value-Inversion.html` | Passcode-gated Decision Canvas. Access code: **`Mission$implify`** |
| `gate_template.html` | Encryption gate template (used by `encrypt_resource.py`). |
| `encrypt_resource.py` | Helper to encrypt new resource HTML into a passcode-gated page. |
| `build_canvas.py` | Generator script for the raw Decision Canvas HTML, edit this, then re-run, rather than hand-editing the generated file. |
| `raw/decision-canvas.html` | Plaintext source of the Decision Canvas (generated by `build_canvas.py`). Do **NOT** publish, this is the unencrypted original. |
| `assets/` | Centene logo files (color + white "reverse" variant) and four generic Microsoft narrative/architecture screenshots reused from the Kaiser Permanente + Risant Health build (no customer-specific branding or numbers in those four), plus `logos-b64.json` (cached base64 encodings used by the build script). |

## Content & format

- **Tabs:** Problem &middot; Status Quo &middot; The Big Question &middot; Opportunity &middot; New Approach &middot; Plan.
- **Problem:** SaaSpocalypse + cost squeeze twin cards, the clickable Then/Now
  Value Inversion stack, the hyperscaler-tax comparison, and the compounding
  cost of a bolted-on data + AI layer.
- **Status Quo:** The Copilot "blind spot" (screenshot, generic), and
  fragmented-context stats reframed around Centene's payer/managed-care
  member journey (enrollment, prior authorization, claims, care management).
- **The Big Question:** Full-bleed pause-moment screenshot (generic, reused
  from the Kaiser Permanente + Risant Health deck), no other content on the tab.
- **Opportunity:** Centene's own $853.7M AI-BPS TAM (App Development / CRM /
  ERP, clickable vendor categories sourced from Centene's Solution
  Infrastructure Tech Stack export), the 10-year savings bar chart modeled at
  $2.99/user/month (Power Apps) and $28.97/user/month (Dynamics 365) against
  Centene's 61,100-employee headcount, and the business-outcome stat cards.
- **New Approach:** The clickable Work IQ / Customer IQ / Fabric IQ / Foundry
  IQ / Web IQ five-thing picker, the Microsoft IQ platform architecture
  diagram (screenshot, generic), six payer-specific "proof it works" cards,
  and a compounding-return line chart (native inline SVG, computed from the
  real Centene savings model, not a static screenshot).
- **Plan:** The "scrutiny vs. the question that matters more" reframe, the
  "what it takes to get there" 3-step list, and the closing statement.
- **Branding:** Theme derives automatically from Centene's own brand colors,
  pulled live from centene.com on 9/8/2026: primary blue `#00598C` (light
  mode), bright cyan `#00B9F2` (dark mode, matches Centene's own dark-background
  accent color), plus indigo `#262768`, magenta `#CB187D`, and green `#2C8641`
  as supporting accents. Supports light/dark themes; the hero logo swaps to
  the white "reverse" variant automatically in dark mode.

## Access code

`Mission$implify`. To rotate it, re-run the encryption step with a new
`--code` value (see below). Note the `$` character: quote it in PowerShell
(single quotes) so it isn't interpreted as a variable.

## Publish to GitHub Pages

> Use your **personal** GitHub account (Pages on the free tier requires a
> personal account and a public repo, not an enterprise account).

1. Create a new public repository (e.g. `cx-centene`).
2. Push `index.html`, `Centene-App-Value-Inversion.html`, and `assets/`
   (excluding `raw/` and `assets/logos-b64.json`, see `.gitignore`).
3. Settings &rarr; Pages &rarr; Source = "Deploy from a branch", Folder = `/ (root)`.
4. Live URL: `https://<your-username>.github.io/cx-centene/`

## Editing the canvas later

Do **not** hand-edit `raw/decision-canvas.html` or the encrypted
`Centene-App-Value-Inversion.html` directly, edit `build_canvas.py` (the
CSS, HTML body, JS data arrays, and the savings-model math are clearly
separated in that file), then re-run:

```
python build_canvas.py
python encrypt_resource.py --in raw/decision-canvas.html ^
    --out Centene-App-Value-Inversion.html ^
    --code "Mission$implify" ^
    --title "Centene Corporation Value Inversion Decision Canvas"
```
